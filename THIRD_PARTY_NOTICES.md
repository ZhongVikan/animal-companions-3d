# Third-party references

This demo is an independent Godot implementation. It does not copy source
files from either reference project.

## Google Pie Noon

Reference: <https://github.com/google/pienoon>

The project is archived and its source is licensed under the Apache License,
Version 2.0. We used its public design ideas as references for a throw / hit /
deflect loop, survival win condition, explicit game state, and a danger-first
CPU decision order. No Pie Noon source code or assets are included here.

## Starship Olympics

Reference: <https://github.com/notapixelstudio/starship-olympics>

The source-code license is MIT. The repository has separate notices for its
art and audio assets, which are not used by this demo. We used its public
structure as a reference for local multiplayer input slots, player selection,
CPU opponents, match scoring, and result transitions. No Starship Olympics
source code or assets are included here.

## Project assets

The seven plush animal models in `models/glb/` are the locally generated assets
from the supplied reference image. They are static meshes with embedded PBR
textures. See the root `README_使用说明.md` for their limits and import notes.
